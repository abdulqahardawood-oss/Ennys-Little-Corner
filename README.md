# Enyy's Little Corner

A small React/Vite starter app for a playful friend page.

## Start it

```bash
npm install
npm run dev
```

## Personal bits

- The three supplied photos are already wired into `public/photos/ennyy-1.jpg`, `public/photos/ennyy-2.jpg`, and `public/photos/ennyy-3.jpg`.
- Opening the envelope reveals the letter and starts the official Spotify player for *We Hug Now* by Sydney Rose. Spotify controls playback and account requirements.
